# O que já aprendi sobre GitHub e Hermes

## GitHub

- Chave SSH permite publicar sem senha.
- GitHub Pages publica páginas HTML estáticas.
- Um repositório precisa ter branch `main` e Pages ativado para publicar.
- `git push` envia o conteúdo local para o GitHub.

## Hermes

- Pode criar arquivos e pastas.
- Pode editar HTML/CSS/JS.
- Pode preparar commits Git.
- Pode publicar via Git quando o acesso SSH está configurado.
- Pode recuperar conversas anteriores com busca de sessões quando necessário.
