# Aula 02 — Comandos básicos de Git

## Ver estado

```bash
git status
```

## Ver mudanças

```bash
git diff
```

## Adicionar arquivos

```bash
git add .
```

## Criar commit

```bash
git commit -m "Descreve o que mudou"
```

## Enviar para GitHub

```bash
git push
```

## Regra de ouro

Commit bom explica a mudança. Evite mensagens como `update` ou `teste`.
