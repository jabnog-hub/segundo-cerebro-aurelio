# Segundo Cérebro — Aurelio

Repositório pessoal de conhecimento, decisões e projetos.

## Trilhos principais

- **Pessoal**: família, casamento, saúde, finanças e assuntos de vida.
- **Profissional**: IA/agentes, automações, GitHub/Hermes, carreira e projetos de negócio.

## Regra de uso

1. Tudo que chegar sem organização entra em `00-inbox/`.
2. Toda decisão importante vai para `04-decisoes/`.
3. Projetos ativos ficam em `02-profissional/projetos/` ou `01-pessoal/`.
4. Aulas e trilhas de aprendizado ficam em `05-aulas/`.
5. Mudanças relevantes devem ser salvas com `git commit` e enviadas com `git push`.

## Estrutura

```text
00-inbox/                         Entrada rápida
01-pessoal/                       Vida pessoal
02-profissional/                  Trabalho, IA, negócios, Hermes e GitHub
03-referencias/                   Materiais de consulta
04-decisoes/                      Decisões com contexto
05-aulas/                         Aulas e trilhas de aprendizado
06-templates/                     Modelos reutilizáveis
```
