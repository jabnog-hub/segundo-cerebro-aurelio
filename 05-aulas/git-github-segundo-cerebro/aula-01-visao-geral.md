# Aula 01 — Visão geral do segundo cérebro

## Objetivo

Entender que o segundo cérebro é um sistema para guardar contexto, decisões, projetos e aprendizados.

## Ideia central

Não é só armazenamento. É um ambiente para pensar melhor e trabalhar com agentes de IA.

## Fluxo básico

1. Capturar em `00-inbox/`.
2. Organizar em pessoal ou profissional.
3. Registrar decisões em `04-decisoes/`.
4. Salvar mudanças no Git.
5. Enviar para GitHub.

## Exercício

Criar uma nota nova em `00-inbox/` com uma ideia real e depois movê-la para a pasta correta.
